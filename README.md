# RimFrost OS

A gaming-first Linux desktop from RimFrost Labs. Your game gets the machine's
full attention while it has focus, and your desktop gets it back the moment you
alt-tab. Instant replay clipping is built in.

RimFrost OS is built on [Bazzite](https://bazzite.gg), which in turn is built on
Fedora Atomic. It inherits Bazzite's gaming stack (Steam, Gamescope, Proton,
HDR, drivers built into the image) and its atomic updates. A bad update can be
rolled back from the boot menu.

> Status: early development. Not ready for daily use.

## Images

| Image | For |
|---|---|
| `ghcr.io/rimfrost-labs/rimfrost-os` | AMD and Intel graphics |
| `ghcr.io/rimfrost-labs/rimfrost-os-nvidia` | Nvidia RTX 20 series and newer |

## Try it

From an existing Bazzite or other Fedora Atomic install:

```bash
sudo bootc switch ghcr.io/rimfrost-labs/rimfrost-os:latest        # AMD / Intel
sudo bootc switch ghcr.io/rimfrost-labs/rimfrost-os-nvidia:latest # Nvidia
systemctl reboot
```

To go back: `sudo bootc rollback` and reboot.

ISO images are built by the "Build disk images" workflow.

## Anti-cheat

Games with kernel-level anti-cheat (for example Valorant, Call of Duty,
Fortnite, League of Legends) do not run on Linux, and no operating system
change can fix that. Keep Windows on a second drive for those. Games using Easy
Anti-Cheat or BattlEye work when the developer has enabled Linux support. See
[Are We Anti-Cheat Yet](https://areweanticheatyet.com/).

## Building locally

Requires podman and [just](https://github.com/casey/just).

```bash
just build                                   # AMD / Intel image
BASE_IMAGE=ghcr.io/ublue-os/bazzite-nvidia-open:stable just build rimfrost-os-nvidia
just build-qcow2 && just run-vm-qcow2        # boot it in a VM
```

Artwork is generated by `branding/make_art.py`.

## Verifying images

Images are signed with cosign:

```bash
cosign verify --key cosign.pub ghcr.io/rimfrost-labs/rimfrost-os
```
